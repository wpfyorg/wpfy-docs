# wpfy stack status

Show shared stack component status.

## Syntax

```bash
wpfy stack status
```

## Examples

```bash
wpfy stack status
```

## Expected Output

- Docker Engine version and status
- Traefik container status and uptime
- Pulled WPFY images listed by tag
- Shared network `wpfy` existence

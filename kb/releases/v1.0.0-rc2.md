# v1.0.0-rc2

## Status

Public RC candidate. Local release gates passed for private commit `5c90ad2`:
552 pytest cases, installer/export checks, security audit, and test-free wheel
and sdist inspection. Disposable-VPS, public-artifact, image-pull, provider,
and available external-scanner evidence remain required before final `v1.0.0`.

## Included

- Audit remediation phases A–F, including safety, restore, runtime ownership,
  systemd/configuration, and bounded runtime paths.
- Package and CLI identity `1.0.0rc2` for tag `v1.0.0-rc2`.
- Public Python tests and CI on push, pull request, and manual dispatch.
- Test-free wheel, sdist, and installed production source payloads.

## Residual Risks And Deferrals

- Traefik Docker socket access remains a documented host-level risk.
- Live WP-CLI, systemd, S3-provider, image-pull, and lifecycle proof is pending.
- Optional external scanners are not represented as passed when unavailable.

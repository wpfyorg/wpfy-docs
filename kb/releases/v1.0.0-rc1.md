# v1.0.0-rc1

## Summary

Release-candidate documentation for the Docker-first WordPress/server administration CLI.

## Status

Planned release candidate. The current docs describe implemented local behavior and retained compatibility surfaces; publish timing depends on the release export and validation path.

## Included Surfaces

- Flat operator commands for site creation, backup, restore, config, runtime, cron, SMTP, Cloudflare DNS, health checks, MOTD, utilities, and version output.
- Retained grouped site and stack commands.
- Local and S3-compatible backup flows, including edge backup/restore.
- Cloudflare-only wildcard SSL.
- Per-site SFTP sidecar management.

## Deferred Or Out Of Scope

- Panel/API/UI.
- OpenLiteSpeed and Bedrock.
- Automatic SMTP notifications.
- Host-stack migration.
- Provider bucket lifecycle API automation.
- Perfect isolation claims.

## Verification

Use [`Validate disposable VPS`](../runbooks/validate-disposable-vps), `npm run docs:build`, and `npm run docs:qa` before publishing documentation.

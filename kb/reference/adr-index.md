# ADR Index

## What It Covers

Accepted architecture decisions relevant to public operators.

## Current Behavior

The current accepted ADR set covers Ubuntu-first support, per-site Compose isolation, SSL preflight before issuance, idempotent commands, Traefik edge proxy, JSON registry, per-site PHP images, non-root operator self-elevation, HTTP-01 handling for proxied domains, deep domain modules, and public PHP image publishing.

## Security Constraints

ADR summaries do not replace the security guide. Follow the command docs and runbooks for operational steps.

## Known Limitations

Some implementation details remain internal. Public docs summarize decisions that affect operators.

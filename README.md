# wpfy Knowledge Base

Source content and publishing tooling for the public wpfy knowledge base at
`https://wpfy.org/kb/`.

The application source remains in
[`wpfyorg/wpfy`](https://github.com/wpfyorg/wpfy). This repository is limited
to public documentation and the tooling used to publish it to WordPress.

## Content

- `content/getting-started/` - installation and first-site guides
- `content/commands/` - CLI command reference
- `content/tutorials/` - task-oriented operational guides
- `content/releases/` - public release notes

Each article should be a standalone Markdown file with a clear title, short
summary, prerequisites where needed, and commands that can be tested directly.

## Publishing

The WordPress publishing workflow is not selected yet. Markdown is the
canonical source until that decision is recorded.
